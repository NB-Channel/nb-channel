chore(worker): nb-channel.top 导航页 Worker —— Netlify 换成 EdgeOne

这个 Cloudflare Worker 是 nb-channel.top 这个【根域名】的导航页
（不是 Pages 站的内容）。之前代码只存在 Cloudflare 面板里，仓库没有存档，
这次一并存进仓库，以后改动能留痕。

【改了哪三处】
1. meta description：
   「GitHub / Cloudflare / PythonAnywhere / Netlify」
   →「GitHub / Cloudflare / EdgeOne / PythonAnywhere」
2. 镜像站列表第四张卡：
   Netlify 站（镜像 · 国内访问更快）
   → EdgeOne 站（镜像 · 腾讯云香港节点）
   图标字母 N → E，链接 netlify.nb-channel.top → edgeone.nb-channel.top
3. 顶部注释的改动记录：补上 2026-10-05 这次的原因和结果

【为什么换】
Netlify 免费版（新版 credit 计划）每月 300 credits，一次生产部署 15 credits，
也就是一个月最多 20 次部署。本站有定时自动提交（Auto update videos /
Auto update fans），每次提交都触发部署，额度很快用光。
额度用完之后 Netlify 不再部署，netlify.nb-channel.top 一直停在
2026-09-27 的 V0.9.7，而 github / cloudflare 两边早就到 1.0.4 了。

换成腾讯云 EdgeOne Pages（edgeone.nb-channel.top）：
    加速区域选「全球可用区（不含中国大陆）」→ 不需要工信部备案
    免费版 500 次构建/月、并发 1、单次超时 20 分钟、4 核 6 GB
    流量与请求不限量，用量超额也不中断服务
    TrustAsia 免费证书，2026-10-05 → 2027-01-03，自动续期（到期前 15 天）

【校验】
node --check 通过；
模板字符串内部分别扫了反引号和 ${}，各 0 个 ——
这一点很关键，因为 Worker 代码里页面是用模板字符串包的，
内联 JS 若含反引号或 ${} 会把模板字符串截断。原代码的注释里也特意写了这条。

【站长要做的】
Cloudflare Workers 面板 → 打开这个 Worker → Edit code →
全选替换为 worker/nb-channel.top.js 的全部内容 → Deploy

【另外】
netlify.nb-channel.top 的 DNS 记录站长已经删了，实测解析不出来 ✅
