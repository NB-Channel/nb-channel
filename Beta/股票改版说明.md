# 虚拟股票系统改版说明

> 2026 年 10 月更新 · 从「注资托底」改为「做市池」模型

---

## 一、为什么要改

**旧版有三个造币口，经济系统被刷坏了**：

```
① 买入时钱消失、卖出时钱凭空出现
   → 系统的货币总量被买卖行为左右

② 「注资」会让所有股东一起白赚
   → 等于凭空印钱分给大家

③ 破产时老板拿走全部市值，股东持仓直接作废
   → 又印一次
```

**有人利用这三条，反复操作刷出了天量 NB币。**

**新版的目标只有一个：让系统里的钱【不多不少】。**

> **你投进去的每一分钱，要么还在你手里，要么还在公司池子里。**
> **系统永远不创造货币。**

---

## 二、新版是什么模型

**每家公司有一个【资金池】，池子里装两样东西**：

```
资金池现金    pool_cash      公司账上的钱
资金池股份    pool_shares    可供买卖的股份
```

**股价 = 池子现金 ÷ 池子股份**

**买卖都是跟【池子】成交，不需要等别人挂单** —— **池子永远是你的对手盘，随时能买卖。**

### 交易怎么影响价格

```
买入 1000 NB币：
    池子现金 +1000
    池子股份 -（按公式算出来的数量）
    → 现金多了、股份少了 → 股价自动上涨

卖出 100 张：
    池子股份 +100
    池子现金 -（按公式算出来的数量）
    → 股份多了、现金少了 → 股价自动下跌
```

**买的人多，价格自然涨；卖的人多，价格自然跌。** **不再需要系统"随机波动"。**

### 为什么这样就不造币了

**因为池子是个封闭的箱子**：

```
你买入 → 你的钱进箱子，你拿走股份
你卖出 → 你的股份进箱子，你拿走钱
```

**箱子里的钱总共就那么多。** **你能套现的上限，就是【箱子里有多少现金】。** **股份再多，箱子没钱也换不出钱来。**

## 三、和你有关的六个变化

### ① 注册公司要出钱了

| | 旧版 | 新版 |
|---|---|---|
| 初始市值 | 白送 20000 | **你自己出资建池子** |

**你出 C 币建公司**：

```
池子现金   = C
池子股份   = C 张        →  股价 = 1.00
总股本     = 2C 张
你（创始人）得 C 张       →  价值 C，正好是你出的钱
池子留     = C 张        →  供别人买
```

**最低出资 20000 NB币。**

### ② 买入：钱进池子了

**旧版买入时钱是"消失"的（既不进公司也不给别人）。** **新版钱【真的进池子】，成为公司的钱。**

**所以买入会推高股价** —— **这是特性，不是 bug。**

### ③ 卖出：输入的是「张数」不是「金额」

**旧版你输入"卖多少钱"，新版你输入"卖多少张股份"。**

**因为 AMM 模型下，卖出的钱取决于池子状态，事先不知道确切金额，只能先定张数、再算能拿多少。**

**页面上会实时显示预览**：预计到账 / 成交均价 / 滑点 / 成交后价格。

### ④ 「注资」没有了

**旧版「注资」= 给自己公司加钱，让市值涨。** **新版取消了。**

**为什么？** **因为注资会让所有股东一起白赚 —— 那是造币。**

**那创始人怎么给公司加钱？** **加不了。** **公司资金池只能靠【别人买入】增长。** **这跟真实市场一致：上市公司也不能自己买自己的股票来撑股价（那叫操纵）。**

### ⑤ 「提取公司价值」没有了，改用「分红」

| | 旧版「提取」 | 新版「分红」 |
|---|---|---|
| 谁能拿 | 只有老板 | **全体股东按持股比例** |
| 效果 | 市值减少，老板拿钱 | 池子钱减少，股价自动下跌（除息） |

**分红要从池子里拿钱，所以股价会同步下跌** —— **这叫「除息」，是真实市场的规则。**

**你拿到现金，但手里的股票同时贬值，总资产不变。**

### ⑥ 「破产」改成「清算」

| | 旧版 | 新版 |
|---|---|---|
| 池子里的钱给谁 | **老板独吞** | **按持股比例分给所有股东** |

**这跟真实市场一致：破产清算时，还完债后剩余资产按持股比例分给股东。**

## 四、怎么玩：三个策略

### 策略一：自己做一家公司（创始人）

```
① 出 20000 建公司 → 你得到 20000 张（股价 1.00）
② 等别人来买 → 他们把钱放进池子，股价上涨 → 你的股份增值
③ 想拿钱 → 发起「分红」，从池子里取钱，全体股东一起分
④ 不想做了 → 「清算」，池子里的钱按持股比例分给所有股东
```

**关键理解**：**股价上涨靠的是【别人买入】，不是你自己注资。** **所以你要做的不是"往里砸钱"，而是"让公司值得被买"。**

### 策略二：买入别人的公司（投资人）

```
① 看中一家公司 → 买入（钱进池子，你拿到股份）
② 公司被更多人看好 → 股价涨 → 你的股份增值
③ 卖出 → 从池子里把钱换回来
④ 持有期间如果创始人分红 → 你也能分到
```

**关键理解**：**你赚的钱来自【后来买入的人】，不是系统给的。** **所以你要判断的是"这家公司会不会有人愿意出更高的价买"。**

### 策略三：自动抄底

**设置规则：某公司股价跌破 X 时，自动买入 Y 币。**

```
可设参数：
    目标股价     跌到这个数以下就买
    每次买入金额   10 ~ 100000
    每日上限     默认 50000
```

**注意**：**只能盯【别人的公司】** —— **不能对自己的公司设自动买入。**

## 五、关于滑点（必须理解的一件事）

**买入金额越大，成交均价越高。** **这个差价叫「滑点」。**

**举例**：

```
某公司池子：现金 20000，股份 20000  →  股价 1.00

你买 100 币：
    均价 1.005      滑点 +0.5%      （几乎没感觉）

你买 1000 币：
    均价 1.05       滑点 +5%        （能感觉到）

你买 5000 币：
    均价 1.32       滑点 +32%       （很痛）
```

**为什么？** **因为你买入时把池子里的现金加多了、股份拿走了，价格自然被你自己推高了。**

**所以**：

```
✅ 小池子公司：小额买入，别一次砸太多
✅ 大池子公司：可以承受较大的单笔买入
✅ 页面上会实时显示滑点，超过 5% 会标红提醒
```

**卖出同理** —— **卖得越多，均价越低。**

## 六、常见问题

**Q：我的公司市值怎么缩水了？**

A：旧版的「市值」是个虚数（注册白送 2 万 + 注资撑起来的，但很多从来没兑现过）。新版按【真实资金】重算，所以数字会变小。**你的股份张数没变，价值也没变**，只是口径改了。

**Q：我的持仓怎么变成「张数」了？**

A：旧版记录的是「本金」，新版记录的是「持有多少张股份」。**数值上你的持仓价值不变** —— 原来"持仓价值 3 万"，现在就是"持股 3 万张 × 股价 1.00"。

**Q：为什么不能买自己的公司？**

A：防止操纵。如果允许，创始人可以自己大额买入拉高价格，吸引别人跟风后砸盘。真实市场也不允许（那叫市场操纵）。

**Q：公司资金池的钱我能拿出来吗？**

A：能，但只有两个途径：**分红**（全体股东一起分）或**清算**（按持股比例分）。**不能一个人独吞。**

**Q：股价会自己波动吗？**

A：不会了。**旧版有"随机波动"和"公司税"在改市值，新版价格【完全由交易决定】。** 唯一还会影响价格的是**公司税** —— 每天从池子里扣一笔，扣完股价自动下跌。

**Q：散户能不能玩？**

A：能。池子小的公司，几百币就能买。**但要注意滑点 —— 小池子公司别一次买太多。**

**Q：怎么知道我赚了还是亏了？**

A：页面上「我的持仓」会显示：持股张数 / 成本均价 / 现价 / 浮动盈亏。**浮动盈亏 = 当前价值 − 你的累计投入成本。**

## 七、一句话总结

> **旧版是「充值推高市值，然后想办法把市值换成钱」。**
> **新版是「用真钱买股份，从后来的人手里赚钱」。**
>
> **系统不再印钱，你赚的每一分都是别人亏的 —— 这才是股票。**
