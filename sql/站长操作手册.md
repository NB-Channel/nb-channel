# 新股票系统 · 操作手册（站长自用版）

> 只讲【你该点哪里、会发生什么】，不解释原理。
> 想了解为什么这么设计，看 `Beta/stock-Beta-help.html`。

---

## 一、先记住一句话

```
股价 = 池子现金 ÷ 池子股份
```

**池子 = 公司账上的一笔钱 + 一堆没卖出去的股份。**

**股价涨 = 池子里现金变多，或者股份变少。**

**就这些。** 下面所有操作都是在动这两个数。

---

## 二、你会看到的七个按钮

打开股票页，找到你自己的公司那一行，点进去，会看到：

| 按钮 | 谁能点 | 一句话说明 |
|---|---|---|
| **买入** | 所有人（不能买自己公司） | 花钱进池子，拿股份 |
| **卖出** | 持股的人 | 把股份还回池子，拿钱 |
| **分红** | 只有创始人 | 从池子拿钱，分给所有股东 |
| **增资** | 只有创始人 | 往池子打钱，**不拿股份** |
| **清算** | 只有创始人 | 解散公司，池子的钱按持股比例分给所有人 |
| **自动抄底** | 所有人 | 设个目标价，跌到就自动买别人的公司 |
| **改版说明** | — | 跳到详细说明页 |

## 三、用你的公司走一遍（假设你有一家「NB频道」）

### 场景 1：你想看看自己公司值多少钱

```
点开「NB频道」，你会看到：
    股价        1.0000
    资金池      20,000 币
    总股本      40,000 张
    我的持股    20,000 张   ← 你作为创始人的
```

**你的钱 = 20,000 × 1.0000 = 20,000 币**（**就是你注册时出的那笔**）

---

### 场景 2：你想让股价涨（**用增资**）

```
点「💰 增资」
输入 10,000
下面会实时显示：
    当前股价      1.0000
    增资后股价     1.5000   ⬆ +50.00%
    你的余额      12,345

点「💰 确认增资」
```

**发生了什么**：

```
你的余额     -10,000      →  2,345
公司池子     +10,000      →  30,000
股价         1.0000  →  1.5000
你的持股     20,000 张 × 1.5 = 30,000 币   （原来 20,000）
```

**你花了 1 万，但你的持股涨了 1 万 —— 看起来不亏不赚？**

**不对。你实际是【亏了 1 万现金，换来了 1 万账面增值】，因为那 1 万进了公司池子，你只能靠分红或清算慢慢拿回来。**

**所以增资是【纯付出】，不是投资。** **它的意义是**：**股价涨了，公司看起来更值钱，更容易吸引别人来买。**

⚠️ **增资后 7 天内，你不能卖这家公司的股份。** **按钮会变灰，鼠标放上去会提示还剩几天。**

---

### 场景 3：别人来买你的公司（**这是真正赚钱的方式**）

```
有人花 10,000 买你的公司
    → 池子现金 +10,000
    → 池子股份 -（按公式算，大约 -6,667 张）
    → 股价从 1.0 涨到约 1.5

你的持股没变（还是 20,000 张），但每股更值钱了
你的钱 = 20,000 × 1.5 = 30,000   （原来 20,000，赚了 1 万）
```

**✅ 这才是你赚钱的方式 —— 别人买入，你的股份自动增值。**

---

### 场景 4：你想从公司拿钱（**用分红**）

```
点「💸 分红」
输入 5,000

→ 池子现金 -5,000
→ 按持股比例分给所有股东
→ 你持股占多少，就分到多少
```

**注意**：**池子的钱少了，股价会同步下跌**（**这叫除息**）。**你拿到现金，但手里的股票同时贬值，总资产不变。**

**为什么还要分红？** **因为这是唯一能把公司的钱变成你口袋里的钱的正常途径。**

---

### 场景 5：你不想做了（**用清算**）

```
点「🧹 清算公司」
→ 池子里剩下的钱，按持股比例分给所有股东
→ 公司消失
```

**⚠️ 不是老板独吞** —— **所有持股的人一起分。** **你占多少股就分多少。**

---

### 场景 6：你想买别人的公司（**买入**）

```
在行情列表里点别人的公司 → 点「买入」
输入金额，比如 1,000
下面会实时显示：
    当前价格      1.0000
    预计成交均价   1.0526   ⬆ 滑点 +5.26%
    预计得到      950.0 张
    手续费        50 币（5%）
    共需支付      1,050 币
    成交后价格     1.1111
```

**关键看「滑点」那一行**：

```
滑点小（< 1%）   →  没问题，买吧
滑点大（> 5%）   →  你这一笔会把价格推高不少，考虑分批买
```

**为什么会有滑点？** **因为你买的时候往池子里放了钱、拿走了股份，价格自然被你自己推高了。** **买得越多推得越狠。**

---

### 场景 7：你想卖出手里的股份（**卖出**）

```
点「卖出」
输入【张数】，不是金额   ← 这个和旧版不一样，最容易搞错
比如卖 500 张
下面会显示：
    预计到账      XXX 币
    成交均价      X.XXXX
    滑点          X.XX%
```

**如果你持有某家公司，但 7 天内给它增过资，卖出按钮会是灰的。**

---

### 场景 8：设置自动抄底

```
点右上角「🎯 自动抄底」
选一家【别人的】公司（下拉里不会出现你自己的公司）
填：
    目标股价    0.9000
    每次买入    2000
    每日上限    50000

→ 以后这家公司股价跌破 0.9，系统自动帮你买 2000
```

## 四、最容易搞混的三件事

### ① 卖出输入的是「张数」不是「金额」

```
旧版：卖 1000 币  →  意思是卖价值 1000 币的股票
新版：卖 1000 张  →  意思是卖 1000 股
```

**因为新版卖出的钱取决于池子状态，事先算不出确切金额，只能先定张数。**

---

### ② 增资 ≠ 买入

```
买入  花钱 → 拿到股份        （股份是你的）
增资  花钱 → 什么都没拿到     （钱变成公司的，全体股东受益）
```

**只有创始人能增资。** **买入不能买自己的公司，增资只能给自己的公司。**

---

### ③「市值」这个数字变小了不代表你的钱少了

```
旧版市值 = 一个可以自己注资推高的虚数
新版市值 = 股价 × 总股本 = 池子里的真钱 × 2

你原来的市值里，有一部分是账面虚增（钱早提走了）
新版只算池子里真正有的钱
```

**你的【个人持股】没变** —— **迁移时按你原来的持仓价值等额换成了股份。**

---

## 五、一句话总结怎么赚钱

```
✅ 别人买你的公司   →  你的股份增值     ← 主要收入
✅ 你买别人的公司   →  等它涨了卖出去   ← 也是收入
✅ 分红            →  把公司的钱搬进自己口袋
❌ 自己给自己增资   →  纯付出，不赚钱，只是让公司看起来更值钱
```

## 六、出问题怎么办

| 现象 | 原因 |
|---|---|
| 买入按钮点不动 | 那是你自己的公司，不能买 |
| 卖出按钮是灰的 | 你 7 天内给这家公司增过资 |
| 提示「休市时间」 | 交易时段是每天 8:00 - 20:00 |
| 提示「正在升级维护」 | 维护模式开着，只有白名单能操作 |
| 买卖价格和预期差很多 | 滑点，池子越小越明显 |
