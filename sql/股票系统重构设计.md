# NB频道 · 虚拟股票系统重构设计

写于 2026-10-03

---

## 零、先定一个原则

**整个系统必须【货币封闭】**：

> 玩家投入的每一分钱，要么还在某个玩家手里，要么还在公司池子里。
> 系统【永远不创造货币】，也【永远不销毁货币】（手续费除外，那是刻意销毁的）。

现在这套系统违反了这个原则：
- 买入时钱消失、卖出时钱出现 → 系统的货币总量被买卖行为左右
- 注资让所有股东白赚 → 凭空造币
- 破产时老板拿走全部市值、股东作废 → 又一次造币

**重构的全部目标就是让上面这三条不再成立。**

## 一、三个可选模型

### 模型 A：订单簿（真正的交易所）

```
玩家挂买单和卖单，系统撮合
买价 ≥ 卖价就成交，成交价成为最新价
```

**优点**：最真实，价格完全由供需决定
**缺点**：
- 需要有人挂单，冷门公司可能几天没人成交
- 要做撮合引擎、部分成交、撤单、涨跌停…
- 对一个虚拟公司游戏来说，工作量过大

**结论**：不建议。

---

### 模型 B：AMM 做市池（恒定乘积）★ 推荐

```
每家公司有一个资金池，池子里有两样东西：
    现金池  (NB币)
    股份池  (股票数量)

交易公式：现金池 × 股份池 = 常数 k

买入：你往池子里放钱，从池子里拿走股份
      → 钱少了、股份少了 → 价格自动上升
卖出：你往池子里放股份，从池子里拿走钱
      → 股份多了、钱少了 → 价格自动下降
```

**优点**：
- **永远有人跟你成交**（池子就是对手盘），不需要等别人挂单
- **天然货币封闭** —— 钱只是在你和池子之间移动，系统不创造也不销毁
- **价格自动发现** —— 买的人多价格自动涨，不用人工干预
- **实现简单** —— 核心就一个公式，几十行 SQL
- **不会归零** —— 池子里永远有钱和股份，价格趋近于 0 但永远不为 0

**缺点**：
- 有「滑点」（买得多，均价越高），但这反而是真实的
- 需要给每家公司一个初始池子（可以由注册者出）

**结论**：最适合你这个场景。

---

### 模型 C：公式定价（现在的做法，改良版）

```
股价 = 公司价值 ÷ 总股本
公司价值由「注资」和「盈利」决定
```

**优点**：改动最小
**缺点**：**「公司价值」这个概念本身没有真实资金来源，无论怎么改公式都会留下造币口**

**结论**：不彻底，只能续命。

## 二、推荐方案：模型 B（AMM）的完整设计

### 2.1 核心概念

```
每家公司有三样东西：
    pool_cash    池子里的现金（NB币）
    pool_shares  池子里的股份（张）
    total_shares 总股本（张）

股价        = pool_cash ÷ pool_shares
公司市值    = 股价 × total_shares = pool_cash × total_shares ÷ pool_shares

玩家持有    holdings.shares 张股份
```

**关键点**：**玩家手里的股份 + 池子里的股份 = 总股本**

```
total_shares = pool_shares + Σ(玩家持有的股份)
```

### 2.2 买入（往池子放钱，拿股份）

```
恒定乘积：pool_cash × pool_shares = k

买入 x 个 NB币：
    新现金池 = pool_cash + x
    新股份池 = k ÷ 新现金池          ← 由恒定乘积推出
    拿到的股份 = pool_shares - 新股份池
```

**价格自动上升**：现金多了、股份少了 → 单价 = 现金/股份 上升 ✅

### 2.3 卖出（往池子放股份，拿钱）

```
卖出 s 张股份：
    新股份池 = pool_shares + s
    新现金池 = k ÷ 新股份池
    拿到的钱 = pool_cash - 新现金池
```

**价格自动下降** ✅

### 2.4 注册公司

```
注册者必须【自己出初始资金】建池子
    比如：出 20000 NB币 → pool_cash = 20000
          发行 20000 张股份 → pool_shares = 20000（全进池子）
          注册者自己先拿到一部分？—— 见下面的"初始分配"

此时股价 = 1.00 NB币/张
```

**⭐ 这是最关键的一处改动**：**初始市值不再是白给的，而是注册者真金白银出出来的。**

**初始分配两种玩法**：

```
玩法一（公平）：注册者不预留股份，全部进池子
    他想持股就自己买，跟别人一样
    好处：绝对公平，没有"创始人白拿"的问题
    坏处：他对公司没有天然控制权

玩法二（创业）：注册者预留一部分
    比如出 20000，发行 40000 张：
        20000 张进池子（池子现金 20000）→ 股价 1.00
        20000 张留给注册者自己
    好处：有"创始人持股"的感觉
    坏处：股价 1.00 时，他自己的股份也值 20000
          等于他出的钱又回到了自己账上 —— 【这是造币！】
          除非…他的股份【不能立刻卖】，有锁定期
```

**建议用玩法一** —— 简单、干净、绝对封闭。**想给自己留股份就自己去买，买多少花多少钱。**

### 2.5 公司拿钱干嘛

**池子里的钱就是公司的钱。** **公司可以用它做两件事**：

```
① 分红：从池子里拿出 x 元，按持股比例分给所有股东
       池子钱少了 → 股价自动下跌（等于除息）
       股东总资产不变，但拿到了现金 ✅ 真实

② 回购：从池子里拿钱买回股份并销毁
       池子钱少了、股份也少了 → 股价上升
       ⚠️ 但这是拿股东的钱抬高股价，等于左手倒右手，实际意义不大
       建议不做，或者只作为一种"信号"行为
```

**⭐ 分红是必须做的** —— **它是"持有股票有回报"的唯一来源，不然玩家只有投机一条路。**

### 2.6 破产清算

```
公司池子里的钱，按【持股比例】分给所有股东
    每个股东拿 = pool_cash × (他的股份 ÷ total_shares)

如果池子里还有股份（池子自己的那部分），那部分对应归零
```

**⭐ 这就对了**：**股东有剩余索取权，按比例分。** **注册者不再独吞。**

**而且没有"注册者特殊退款"这回事** —— **他拿到的就是他持股对应的那份。**

### 2.7 公司税

**改成【从池子里扣】**：

```
每天从 pool_cash 里扣一笔
    pool_cash 减少 → 股价自动下跌
    ⚠️ 注意：扣钱会让池子的恒定乘积 k 变小
        这是允许的 —— k 只在交易中守恒，外部注入/抽取会改变它
```

**税率按池子现金分档，逻辑不变。**

### 2.8 随机波动

**⭐ AMM 模型下【不需要随机波动】** —— **因为价格完全由池子里的资金和股份决定，玩家交易就会推动价格。**

**但如果池子里长期没人交易，股价就完全不动，看着很死。** **可以加一个可选机制**：

```
每天随机注入/抽取一点池子里的现金
    → 制造"市场情绪"的效果
    → 但要双向对称，长期均值为零
```

**建议先不做，看实际效果再说。**

    id           bigserial PRIMARY KEY,
    user_id      uuid NOT NULL,
    company_id   bigint NOT NULL,
    side         text NOT NULL,          -- buy / sell
    cash         numeric NOT NULL,       -- 花了/拿到多少钱
    shares       numeric NOT NULL,       -- 拿到/卖掉多少股

    ON public.stock_trades (company_id, created_at DESC);

## 四、核心函数（伪代码，实际 SQL 我可以直接写）

### 4.1 买入

```sql
FUNCTION buy_stock(p_user, p_company, p_cash, ...)
BEGIN
    校验：金额 > 0、在交易时段、不是自己公司、余额足够（含手续费）

    -- 恒定乘积
    k        := pool_cash * pool_shares;
    new_cash := pool_cash + p_cash_after_fee;
    new_shares := k / new_cash;
    got_shares := pool_shares - new_shares;

    -- 更新池子
    pool_cash   := new_cash;
    pool_shares := new_shares;

    -- 更新玩家持仓
    holdings.shares += got_shares;

    -- 扣钱
    profiles.nb_balance -= (p_cash + fee);
END
```

**⭐ 注意：钱【进池子】了，所以在系统里没消失 —— 只在池子和玩家之间移动。**

### 4.2 卖出

```sql
FUNCTION sell_stock(p_user, p_company, p_shares, ...)
BEGIN
    校验：股份 > 0、在交易时段、持有足够

    k          := pool_cash * pool_shares;
    new_shares := pool_shares + p_shares;
    new_cash   := k / new_shares;
    got_cash   := pool_cash - new_cash;

    pool_cash   := new_cash;
    pool_shares := new_shares;

    holdings.shares -= p_shares;
    profiles.nb_balance += (got_cash - fee);
END
```

### 4.3 分红

```sql
FUNCTION pay_dividend(p_company, p_amount)
BEGIN
    只能由公司注册者发起（或者系统按利润自动分）
    池子现金 >= p_amount

    pool_cash -= p_amount;

    -- 按持股比例分给所有持仓者
    FOR each holder:
        his_cash := p_amount * (his_shares / total_shares);
        profiles.nb_balance += his_cash;
END
```

### 4.4 破产清算

```sql
FUNCTION bankrupt_company(p_user)
BEGIN
    池子里的现金按【总股本】平分
    FOR each holder (含池子自己那份):
        his_cash := pool_cash * (his_shares / total_shares);
        profiles.nb_balance += his_cash;

    删除所有持仓、删除公司
END
```

## 五、迁移已有数据

**这是最麻烦的一步。** **现在有 93 家公司在跑，不能直接清空。**

**思路：把旧的「本金 + 基准市值」换算成「股份」**

```
对每家公司：
    ① 定一个新股价，比如 1.00 NB币/张
    ② 总股本 = 旧市值 ÷ 1.00
    ③ 池子股份 = 总股本 × 某个比例（比如 50%）
    ④ 池子现金 = 旧市值 × 同一比例
    ⑤ 每个股东按他的持仓价值换算成股份：
           他的持仓价值 = principal × (旧市值 ÷ base_market_value)
           他的股份 = 他的持仓价值 ÷ 1.00
    ⑥ 剩余的股份进池子
```

**举个例**：

```
旧数据：某公司市值 100 万，池子比例定 50%

新数据：股价 1.00
        总股本 = 100 万 ÷ 1.00 = 100 万张
        池子  = 50 万张 + 50 万现金
        股东 A 持仓价值 20 万 → 20 万张
        股东 B 持仓价值 30 万 → 30 万张
        （50+20+30 = 100 万张 ✅ 对得上）
```

**迁移后立刻验证**：
```
① 每家公司：pool_shares + Σ持股 = total_shares
② 全站：Σ余额 + Σ池子现金 = 迁移前的 Σ余额 + Σ旧市值
   （如果对不上，说明迁移脚本有 bug）
```

## 六、改完之后，那些漏洞还成立吗

| 原来的漏洞 | AMM 模型下 |
|---|---|
| 注资让股东白赚 | **不存在** —— 没有"注资"，想持股就自己买 |
| 买入钱消失、卖出钱出现 | **不存在** —— 钱在池子和玩家之间移动，总量守恒 |
| 破产老板独吞 | **不存在** —— 按持股比例分 |
| 注册白给市值 | **不存在** —— 注册者必须自己出钱建池子 |
| 小号配合套利 | **理论上仍可能，但【不造币】** —— 两个号之间倒腾，钱只是转移，总量不变 |
| 一次最多刷 50 亿 | **不可能** —— 池子里的钱就那么多，卖不出超过池子现金的价值 |

**⭐ 最后一条特别重要**：**AMM 模型下，你能套现的上限是【池子里有多少现金】。** **池子钱不够，你手里的股份再多也卖不出钱。**

**这就是为什么它能根治 —— 它把"凭空造钱"变成了"从池子里分钱"，而池子里的钱是有限的、有来源的。**
